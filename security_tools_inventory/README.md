# Security Tool Inventory (CLI)

A simple command-line Python application for managing a cybersecurity tool inventory. This project was built to practice Python fundamentals such as dictionaries, functions, loops, file handling, and basic automation.

## Features

* Display all security tools
* Search for a tool
* Add new tools
* Prevent duplicate tool entries
* Remove tools with confirmation
* Count total tools
* Save inventory to a text file
* Load inventory from a text file
* Automatic inventory save on exit

## Technologies Used

* Python 3
* Command Line Interface (CLI)

## Concepts Practiced

* Variables
* Dictionaries
* Functions
* Loops
* Conditional statements
* File handling
* Error handling basics
* String methods
* `os` module

## How to Run

1. Clone the repository.

```bash
git clone <repository-url>
```

2. Navigate to the project folder.

```bash
cd Security-Tool-Inventory
```

3. Run the application.

```bash
python file.py
```
